# 路线图 · ScholarlyOps

完成标准以可验证结果为准，不以“文件已创建”为完成。

## Phase 1 — 项目基础

**交付物**：中英文 README / 安装 / 架构；产品规格与路线图；贡献与安全；`.gitignore` / `.editorconfig`；`.agents/skills/`；许可证待决记录；`project.json`。

**验收**：

- [x] 文档路径与目录一致，无虚假功能说明
- [x] 四 Skill 均有有效 `SKILL.md`
- [x] 验证工具可运行
- [ ] 维护者确认正式 GitHub 远程地址
- [ ] 维护者确认许可证并添加 `LICENSE`
- [ ] 商标/品牌法律核查（轻量级检索 ≠ 法律清核）

## Phase 2 — 论文审计核心 Skill

**交付物**：`manuscript-audit` 完整基础流程；参考规范；合成评测；基础自动检查；测试记录。

**验收**：

- [x] 合成案例覆盖数值/单位、四舍五入容差、格式差异、表—图—正文、摘要—结果—结论、因果、引用、术语、方法—结果、证据不足、对照等（现 24 案例）
- [x] 报告区分确定性检查与语义判断；本地运行器对语义案例 skip 而非假通过
- [x] `python tools/run_evals.py` 可重复运行并写出 JSON/Markdown 汇总
- [x] Cursor 人工验收指南已提供（加载实测仍待用户勾选）
- [x] Agent 语义盲测协议：中英指南、rubric、scorecard、盲测包准备脚本（**实测分数待真实盲测后填写，禁止虚构**）
- [ ] Wave A 七个语义案例完成有效盲测并人工评分
- [ ] 维护者真实（可脱敏）稿件试跑记录
- [ ] Cursor IDE 发现/调用 `manuscript-audit` 的实测记录
- [ ] 有证据后才可将成熟度升至 Beta

## Phase 3 — 研究上下文与证据写作

**验收**：

- [ ] 各至少 3 个合成输入→输出案例
- [ ] 与审计 Skill 术语表一致
- [ ] 单目录复制后可独立按 `SKILL.md` 运行

## Phase 4 — 审稿回复闭环

**验收**：

- [ ] 意见—修改—证据—状态模板稳定
- [ ] “禁止声称未完成实验已完成”案例通过
- [ ] 可选衔接审计报告的示例

## Phase 5 — 拓展能力（规划）

文献核验、科研绘图、统计报告检查、期刊规范、知识管理、汇报材料、跨 Agent 兼容实测。**未实现即不算完成。**

## Phase 6 — 开源发布准备

许可证确定、测试通过、文档与安全检查完成后，再 tagged 发布。本次任务不执行 push 或正式发版。
