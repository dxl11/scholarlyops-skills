# 学术完整性摘要（随 Skill 分发）

供独立安装的 `evidence-writing` 使用。

## 写作红线

- 不创建数据、实验、文献或研究限制。
- 不因“更学术”而拔高证据强度。
- 重要主张尽量可追溯到用户材料中的位置。

## 证据状态

`verified` | `partially_supported` | `unverified` | `unsupported` | `conflicting`

## 引用分层（若涉及文献）

1. 存在性 2. 元数据 3. 内容支持 4. 论证恰当性  

仅核对 DOI 不等于内容已验证。

## 可追溯改写

原文 / 修订 / 理由 / 证据位置 / 是否改原意 / 待作者确认。默认不覆盖原稿。
