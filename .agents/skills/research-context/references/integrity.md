# 学术完整性摘要（随 Skill 分发）

本文件供独立安装的 `research-context` 使用，与 ScholarlyOps 产品规格保持一致。

## 不得擅自改变

样本量与次数、数值与单位、设计与对照、相关 vs 因果、显著性与置信区间、结论范围、文献原意。

## 证据状态

| 状态 | 含义 |
|------|------|
| verified | 当前材料足以支持 |
| partially_supported | 仅部分支持 |
| unverified | 尚未核查 |
| unsupported | 现有证据不支持 |
| conflicting | 证据冲突 |

模型“合理猜测”不得标为 `verified`。缺少证据不等于结论为假。

## 输出纪律

- 不编造实验结果。
- 重要改写保留原文与修订理由（若本 Skill 产生改写建议）。
- 默认生成新文件，不覆盖用户原稿。
