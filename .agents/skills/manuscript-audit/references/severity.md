# 严重程度

| 级别 | 使用条件 |
|------|----------|
| Critical | 有明确文本证据的关键科学冲突（例如同一指标两处互斥数值且超出容差；无依据的因果坐实） |
| Major | 显著影响可信度的不一致或关键证据缺失 |
| Minor | 术语、次要措辞、非关键不一致 |
| Needs Review | 需人工/作者判断；证据不足时的默认上限 |

**禁止**：无来源支持的问题使用 Critical/Major。  
**禁止**：把“无法核查”自动升级为已确认错误。  
**禁止**：把“本次未发现”写成“证明不存在错误”。

四舍五入/格式差异见数值脚本的 tolerated 分类，不得直接报 Critical。
